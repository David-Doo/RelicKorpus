The Gesellschaft Project

A controlled archival and management system designed to protect accuracy while preserving structured freedom.

Institution Charter

The Gesellschaft hierarchy is: User > Enforcer > Admin > Core. Accounts are created by Admin or Core only.

  • Users can view public files and restricted summaries, then submit access requests.
  • User edits are marked in bold and tagged with the editor's ID.
  • Enforcers can edit without bold insertion and submit moderation lock requests (up to one week).
  • Admins manage users, approval workflows, and tasking.
  • The Core governs and maintains the complete system.
